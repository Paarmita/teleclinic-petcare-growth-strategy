# PetDoc case study: Care Loop

Case study for the Senior Product Manager, Patient Experience role at PetDoc. It argues for one lead bet, Care Loop (the vet-set check-in), to lift the 180-day second-consultation rate, and includes a clickable prototype.

**Read it here: https://petdoc-case-study.netlify.app/**

## What is in this repo

- `petdoc_case_study.html`: the case study, a single self-contained page with the prototype embedded. Netlify serves it at the site root.
- `PetDoc Prototype.html`: the clickable prototype on its own.
- `petdoc_case_data_EN.csv`: the case data the numbers come from.
- `assignment.md`: the assignment brief.
